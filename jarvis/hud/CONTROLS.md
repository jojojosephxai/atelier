# Keyboard & gestures

| Input | Action |
| --- | --- |
| **Space** (when not typing) | Toggle mic |
| **Esc** during boot | Skip boot |
| **Enter** in command box | Send |
| **Brief me** button | Morning/status briefing |
| **Double-click orb** | Re-run briefing salute |
| Mic button | Push-to-talk |

Spoken / typed phrases the local brain knows: `brief me`, `school tonight`, `swim`, `atelier`, `who am I`, `sleep`, `research watch`, `help`.
