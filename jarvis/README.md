# Joseph’s Jarvis (movie aesthetic)

Goal: a **movie-style Jarvis** — cinematic startup, HUD, voice — that knows you, helps with school/life/coding, runs on **phone + computer**, without burning **Grok Bot** usage.

**You already have:** Cursor Pro + SuperGrok  
**Do not use:** Grok Bot (too expensive for this)  
**Face (UI):** [OpenDex](https://github.com/wassgha/opendex) Jarvis HUD (downloadable)  
**Coding hands:** Cursor Agent / Cloud Agents  
**Know-me memory:** your merged About Joseph markdown → Cursor Rules + the profile file here

## First thing to run (right now)

1. Open [INSTALL-OPENDEX.md](./INSTALL-OPENDEX.md) and install OpenDex for your OS.  
2. Pick theme **Jarvis HUD** in onboarding.  
3. Paste your merged About Joseph into [JOSEPH.profile.template.md](./JOSEPH.profile.template.md) (rename to `JOSEPH.profile.md`).  
4. Add the short User Rule from [CURSOR-WIRING.md](./CURSOR-WIRING.md) in Cursor → Customize → Rules.
